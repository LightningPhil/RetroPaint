# RetroPaint

A tactile painting toy and image editor: chunky tools, live ink, symmetry, stamps, a spirograph kit, and familiar Paint editing tools.

**User stories and intended behavior:** [Start here in APP-USE-CASES](APP-USE-CASES/START-HERE.md) — 349 paired stories and use cases, a searchable catalogue, feature coverage and test data for three experience levels. The [acceptance audit](APP-USE-CASES/runs/2026-10-19-full-audit/README.md) records actual results, evidence, fixes and remaining work.

**Author:** Philip Leichauer  
**License:** [MIT](LICENSE)

**Latest focused checks:** [Basic / Advanced modes and 3D verification](APP-USE-CASES/runs/2026-10-29-modes-cad/README.md) — workspace separation, tube precision fixes, regression results and independently checked STL downloads.

## Scripts

```bash
npm install
npm run dev      # http://localhost:8080
npm run build    # typecheck + compile to dist/
npm run preview  # serve dist/ on port 8080
npm test         # painting, geometry and responsive UI regressions
npm run test:workshop # native mode/CAD controls and independent STL checks
```

Requires Node 20+.

## GitHub Pages

Pushes to `main` (or `master`) run `.github/workflows/pages.yml`, which compiles the app and publishes `dist/`. In the repo settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The Vite `base` is `./`, so the site works at `https://<user>.github.io/RetroPaint/`.

There is no test workflow. Do not add one.

RetroPaint starts in **Basic mode** for painting and play. In **More**, turn on **Advanced mode** for layers, editable vectors, Photo lab, super resolution and the 3D workshop. The choice is remembered on this device. Switching modes keeps the same picture, layers, live ink, photo recipes and 3D models; it never flattens them. Basic creates raster artwork, while Advanced restores the project's chosen Raster / Vectors setting. Existing editable pieces remain selectable in Basic; their precision controls live in Advanced. The canvas fills the space left by the tool bin, top bar, and material tray. Save downloads a PNG.

## Painting and playing

- Brushes & pens: marker, biro, calligraphy, textured poster paint, and watercolour. Open **Classic brushes** for a one-pixel pencil, classic brush, oil brush, crayon and natural pencil. Sizes run from 1 to 96 pixels.
- Spray: fine mist, splatter, or paper confetti. Pick Rainbow for multicoloured confetti.
- Smudge: drag to push wet paint with a smooth, feathered edge. Size controls the radius; Strength controls the push.
- Shapes: lines, rectangles, circles, polylines and smooth splines. **More shapes & fill** adds ovals, rounded rectangles, polygons, triangles, diamonds, pentagons, hexagons, stars, hearts, lightning, arrows and speech/thought bubbles. Choose brush or solid outlines, and primary/secondary colour fills. Hold Shift to constrain proportions or snap lines to 45° angles. Tap path points, then Finish path or Enter; Polygon closes automatically.
- Select: rectangle, lasso, or a connected-colour wand. Drag a piece or its corner handles to move or resize it; Shift keeps proportions. **More edits & transforms** provides select all, invert selection, delete, flip, rotate and crop. Transparent white paper removes white pixels when placing a piece. Copy also writes a PNG to the system clipboard when the browser allows it; the session clipboard remains available as a fallback.
- Text: choose a font, size, alignment, bold, italic, underline, strike-through and transparent or opaque background. Tap the paper to position it, then Place text. The result becomes a selection that can be resized or rotated. Ctrl+Enter also places text.
- Advanced annotations: in **Text → Text type → Label + arrow**, enter a label and place it. The box fits its words, wrapping at Box width, and defaults to black text, white fill, a thin black border and slightly rounded corners. Choose colours, size, border and square or rounded corners. With Select, drag the blue arrow-tip handle to change the target, or the blue centre handle to move only the box; the connection follows the nearest edge automatically. Drag elsewhere on the box to move the whole annotation. **Selection options → Edit label** changes the words and style. Labels above 3D get an annotation layer automatically when needed. Save project preserves their editability and image export includes the arrows.
- Pick colour: sample the visible picture, including other layers. Right-click samples the second colour; right-click while drawing uses it. The colour wheel also accepts exact hex and RGB values.
- Symmetry: vertical, horizontal, 4, 6, 8, 10 or 12 ways.
- Stamps: 131 pictures across eight illustrated categories, with size, turn and flip controls.
- Spiro: move the outer ring, resize using the yellow handle or Ring radius field, and choose gears. Opening it leaves paper colours unchanged.
- Neon and Glitter: choose a colour first, then the special ink. Glitter is stationary metallic pigment; Neon has a coloured halo and a bright centre.

## Editing toolbox

The **More** button opens four drawers within the existing layout:

- **File:** new/open/insert images, paste screenshots, redo, print, recent drafts, and save as PNG, JPEG, WebP, BMP, GIF or TIFF. Drag files onto the paper to insert them. Save/open `.retropaint` projects to keep layers and animated ink.
- **Image:** crop, resize in pixels or percentages, change paper size without scaling artwork, rotate by any angle, flip, skew, and invert colours. Tick **Transform the selection** to edit a piece instead of the whole image. Turn off smooth resizing for pixel art. Edge background removal clears the region connected to the top-left corner; adjust bucket/wand tolerance for flat-colour backgrounds.
- **Advanced:** turn **Advanced mode** on to show **Layers** and **Photo lab** in the main tool palette. The setting is remembered on this device. Turning it off hides their controls without changing layers or saved adjustments. The Layers button opens the stack. Choose **New layer** for a clear sheet, tap a preview to paint on it, use the eye to show/hide it, and drag the dots to change which sheet sits on top. The selected sheet says **Painting here**. Live thumbnails show your animated ink. **Layer options** holds rename, opacity, duplicate, remove, move up/down and combine. On a phone the stack closes after adding or choosing a sheet. Press **L** to toggle it; arrow keys choose a sheet and Alt+↑/↓ reorder it. New layers erase to transparency. Hide Paper to export transparent artwork; JPEG and BMP flatten transparency onto white. Undo/redo restore layer edits and live ink; combining layers captures the current animation frame.
- **View:** fit, actual pixels, zoom/pan, pixel grid, rulers, full screen, **Sound & feel** and **Shortcuts**. Ctrl/Cmd+wheel zooms; Move paper or Space+drag pans. View changes never change saved image resolution.

Images are limited to 4096 × 4096 pixels, 16 layers and 64 million pixels across layers. GIF uses a 256-colour palette and binary transparency. TIFF import supports uncompressed 8-bit RGB/RGBA or greyscale. Projects and images stay in the browser; no server or account is required. Microsoft Paint's service/device-dependent generative AI features are not included.

## Photo lab

Enable **Advanced mode** in **More**, then open **Photo lab** from the main tool palette (or press **P**). Photo lab matches the Layers palette width (260 pixels on desktop). Choose a category and adjustment group; short screens combine them in one grouped selector. The lab remembers your controls and last adjustment group. **Open photo** takes you straight back into the lab after importing; cancelling the file picker restores your draft. **Before** compares with the original, **Reset** clears every adjustment, and **↺** resets the current group. Double-click a slider to restore its default. **Done** saves editable adjustments on the selected layer without changing its original pixels or live ink. Reopen the lab to continue editing or reset, even after Undo history has expired. **Cancel** discards only the current draft. Phone layouts include an interactive small preview for cropping, neutral sampling and horizon alignment.

The **Photo look** dropdown stays visible in every category. **Normal** restores the exact settings from before a look was tried. Switching looks always starts from that baseline, so presets do not accumulate. Any manual adjustment, curve edit, crop or automatic correction shows **Custom**. Selecting Normal after tweaking a look still restores the pre-look baseline. The selected look and baseline are retained in projects.

- **Light:** exposure in stops, brightness, contrast, highlights, shadows, whites, blacks, automatic tone adjustment and quick looks.
- **Colour:** relative temperature and tint, automatic white balance, neutral-point sampling, saturation, vibrance, hue and an eight-range HSL mixer.
- **Curves:** smooth RGB, red, green and blue curves. Tap to add points, drag to move them, or enter exact input/output values. Arrow keys adjust the selected point and Delete removes interior points. Curve presets include a gentle S, faded blacks and lifted shadows.
- **Detail:** sharpening amount/radius/threshold, texture, clarity, Pop, dehaze, luminance noise reduction and colour noise reduction. Pop is RetroPaint's blend of local contrast, vibrance and dehaze, not Adobe's proprietary processing.
- **Effects:** dark or light vignette with midpoint, feather and roundness; deterministic, achromatic film grain with Amount, Size and Roughness. Correlated grain clumps follow luminance, preserve hue and alpha, and stay fixed between renders.
- **Geometry:** free or fixed-ratio crop with exact pixel fields and draggable corners, a thirds grid, horizon straightening, flips, scale, perspective, barrel/pincushion distortion and red/blue fringe alignment. Lens corrections are manual rather than camera-profile based. Alignment and lens controls affect the selected sheet. Crop sets a shared visible frame; every layer retains its full pixels outside the frame. Geometry shows the full source so you can extend or remove an earlier crop.

The RGB histogram reports shadow/highlight clipping. Previews and display renders use disposable caches; original pixels, animated ink and adjustment recipes remain separate. Full-size image exports render the saved recipes and visible frame. **Save project** keeps the originals, editable adjustments, looks and hidden crop margins for later; PNG/JPEG and other image exports contain the finished picture. Version 1 projects remain readable. These controls work on decoded RGB/RGBA images, rather than camera RAW sensor data.

Keyboard: Ctrl/Cmd+Z undoes; Y or Shift+Z redoes; A selects all; C/X/V copy, cut and paste; D duplicates selected editable pieces; O opens an image; S saves a PNG; P prints. Delete removes a selection; Escape cancels; Enter places a floating selection or finishes a path. B/S/A/G/E/F/I/T/R choose brushes, shapes, stamps, Spiro, eraser, bucket, picker, text and selection. M toggles sounds; +/− zoom; 0 fits the picture; ? opens shortcut help. Arrow keys nudge selections by one pixel, or ten with Shift. Selecting a new tool places a floating selection.

## A more comfortable workspace

The palette keeps fixed illustrated tool slots in both basic and advanced modes. Brush choices show samples made with the actual paint renderer. Brush, eraser, spray and smudge footprints remain readable at every zoom; stamps have a translucent placement preview, and the picker magnifies nearby pixels with an exact hex colour. Pen strokes use coalesced pointer samples when the browser provides them, preserving the curve between screen refreshes.

The lower workspace controls show the current tool, size, strength, picture dimensions, zoom and Redo. With a selection, they offer **Place**, copy, duplicate, delete and options. **Bring selection to paper** appears when a piece extends beyond the canvas.

Selections can move freely across every paper edge. Before placement, moving a piece back restores its whole source. On **Place**, a raster keeps only its in-canvas pixels, at its existing position and resolution. Rotated, flipped and skewed rasters retain their transform and clean edges; live raster ink keeps its animation within the permanent trim. Undo restores the discarded pixels. Vectors retain their complete geometry off the paper and can return intact. A faint desk preview makes the overhang visible and draggable. Clicking blank desk space places and deselects; Escape also places editable pieces, while cancelling an ordinary floating raster selection.

**Sound & feel** offers four desk colours, reduced interface motion, master sound on/off, volume and painting sounds. The 23 synthesized sounds use soft attacks, filtered material textures and bounded voices: wooden taps, droplets, paper sounds, pencil strokes, a gentle motor, and distinct Undo, Redo, Place and Save feedback. The speaker next to the zoom controls is a quick mute. Preferences are remembered on this device; live artwork continues to animate when interface motion is reduced.

Static pictures stop repainting while idle. Cursor feedback redraws independently, and animated inks, wet drips, Photo lab previews and motor drawings continue to refresh. Project PNG encoding runs asynchronously in small batches from a stable snapshot, so later edits cannot leak into a project already being prepared.

## Local draft recovery

After editing pauses, RetroPaint saves an editable draft in this browser. A small **Resume** prompt offers the previous picture after a refresh without blocking the ready canvas. **More → File → Recent drafts** shows paged previews of up to eight recent pictures. Restoring preserves vector geometry, live ink, layers and Photo lab recipes; Undo returns to the picture that was open before restoring. Separate working IDs protect pictures in duplicated tabs.

Drafts stay on this device and rotate within a 128 MB budget. Automatic saving waits for active gestures, floating raster selections, text and Photo lab drafts to finish. Pictures above 24 million stored pixels or 50 million serialized characters use **Save project** instead, keeping the drawing controls responsive. Browser storage availability and clearing affect these recovery copies; **Save project** keeps an independent `.retropaint` file.

## Vectors and editable pieces

Choose **More → Advanced mode → Draw with → Vectors** to keep shapes, lines, Spiro drawings, text and stamps as editable geometry. Brushes and spray remain raster: every gesture has its own cropped pixel surface inside its current layer. These pieces do not add rows to the Layers palette. Images and pasted artwork are editable pieces too; paint made before switching modes is retained as one existing-artwork piece.

Use **Select** to click a piece or drag a box around several. Drag to move; pull the gold corner or side handles to resize. Shift-click adds or removes pieces, Shift-drag keeps proportions while resizing or locks the main movement axis, and Alt-click reaches a piece behind another. The piece dropdown also reaches artwork outside the paper. **Exact size & arrange** groups pixel sizes, exact left/top positions (including negatives), centre-on-paper, arbitrary rotation and stacking controls into tabs. Arrow keys nudge by one pixel, or ten with Shift. Delete, copy/paste and Undo/Redo work on pieces. Vector size is independent of paper size, and resizing a raster piece reuses its original pixels until placement trims an overhang. Pixel effects work on the selected piece; neighbouring pieces stay separate.

Switching back to **Raster** changes how new shapes are drawn and retains existing editable pieces. **Save project** writes version 13 for script models, version 11 for connected annotations, and otherwise version 10, with geometry, stroke images, transforms, live ink, photo recipes, editable CAD feature history, sketch dependencies, dimensions, constraints, edge finishes, shells, lofts, sweeps, imported STL meshes and saved picture placement. Version 1–12 projects remain readable. Image exports render the current visible composition. Spiro starts at a size proportional to the paper and its radius field accepts custom pixel sizes beyond the old 60–290 range. Advanced mode uses the same fixed tool slots as the basic palette.

## 3D workshop

Choose **More → Advanced mode → 3D workshop** to build in **millimetres**. The workshop keeps the illustrated buttons, colours and sounds of the paint tools. It loads its renderer and modelling engine only when opened. **Paint** returns to your painting; 3D layers keep transparent image previews while their editable solids remain separate.

- **Shapes:** cubes, spheres/ellipsoids, cylinders, cones, tori, tubes, pyramids and wedges. New pieces share the current **3D** layer. **Layers** can create additional 3D layers, rename/show/hide them, select, hide or lock individual pieces, and move selected pieces to another 3D layer. These layers also appear in the normal paint stack. Their solid data cannot be flattened by the paint-layer merge action.
- **Picture layers & placement:** **Inspect → Picture layers & placement** (also linked from Layers) shows the working CAD layer between the real picture layers below and above it, including photos, painted pixels, vectors and saved Photo lab settings. The workbench uses a picture-shaped frame so its camera and picture export agree. Orbit/pan/zoom to place the model, then **Keep this view in the picture**, or return to Paint. The view is shared across 3D layers and saved in the project; rebuilding geometry keeps that placement. **Paint above 3D** and **Paint below 3D** create an adjacent transparent picture layer, open Paint and show the layer stack in one Undo step. Reorder, rename, hide and change layer opacity with the normal Layers controls. CAD stays editable, previews stay transparent, and painting targets its own sheet. Other 3D layers appear as their saved previews in this composition, respecting sheet order. Switch the picture view off to work on the complete 3D scene.
- **Inspect:** **Projection & views** offers perspective or true orthographic projection and top, bottom, front, back, left, right and isometric views, plus Fit selected. **Measure in mm** picks two surface points, snapping nearby mesh vertices, and reports distance, XYZ differences and the angle between the picked face normals. Measurements are temporary, and curved meshes measure their sampled vertices. **Cutaway & display** offers axis/offset/direction controls, translucent X-ray and wireframe. Cutaways reveal surfaces without capping the inspection plane. Leaving Inspect restores the ordinary display; cached pictures and STL always contain the complete solid.
- **Import STL:** **Shapes → Import STL** or **Inspect → Import STL** reads binary and ASCII STL locally. Choose mm, cm or inches; optionally centre the model on the bed. The importer welds shared vertices, repairs connected face winding, preserves enclosed cavities and rejects open or non-manifold surfaces before changing the document. Up to 200,000 triangles / 20 MB per file. The imported base mesh is retained in History beneath later cuts/joins, with editable transforms and sizes; STL contains no original sketch parameters. Precision B-rep edge and shell tools support imported meshes up to 3,000 triangles; mesh booleans and printing support the full import limit. Project save/reopen retains the original mesh and later recipes.
- **Edit:** coloured move arrows, rotation rings and size handles; exact XYZ position, rotation and local dimensions; proportional resizing, tube wall thickness, colours, duplication, deletion and drop-to-bed. Shift-click selects several pieces. **Snap** sets the translation grid and rotation increment. Mouse drag orbits, right-drag pans and the wheel zooms; touch uses OrbitControls’ one/two-finger gestures. The view buttons give top, front, right, perspective and fit views. On phones, **Tools** opens and closes the panel so the workbench stays available for drawing.
- **Sketch:** opens with Rectangle ready and the workplane facing you. Choose XY, XZ or YZ, or **Pick flat face** and tap a solid face. Click two opposite corners for a rectangle, or the centre then edge for a circle (dragging also works). Tap polygon corners and close by tapping the first corner (or Finish/Enter), or enter exact dimensions. A filled profile and drawing-side **Pull**, **Cut** and **Through hole** buttons appear. Pull/Cut opens a translucent volume preview: drag the depth handle up or down (or use arrow keys / exact depth), then **Apply**. Green previews added material, red previews removed material. **Cancel** leaves the document unchanged. **Next** also opens the exact depth controls. Face sketches default to **Auto**: positive depth adds material, negative depth cuts it, keeping one editable solid. Choose **New piece** to keep it separate, or **Cut** and **Cut all the way through** for a through-hole. Taper and twist shape the extrusion. **Revolve this sketch** spins the drawn outline around its left edge in the original workplane; the profile editor lets you adjust it before making the solid. The separate **Revolve** presets spin closed radius/height profiles around Z through 1–360°. Vase, goblet and knob profiles are starting points; drag profile points or enter coordinates to make your own, including hollow forms.
- **Build:** union, subtract, intersect and convex hull; align centres or edges along X/Y/Z; touch before/after a reference with an optional gap; centre/drop assemblies on the bed; snap two picked flat faces together with opposing normals; linear and circular copy patterns; local-axis mirroring. Subtract uses an explicit target piece. Solids retain their construction recipes and Undo/Redo restores prior geometry and layers.
- **History:** select a solid, then choose **History** or **Edit original features & sketches**. The feature tree retains the original primitives, sketches, extrusions, cutters, revolutions and boolean inputs. Edit original sketch dimensions or points, hole diameters, extrusion depth/direction/taper/twist, tube walls, revolve angles and sketch planes/axes. Face sketches follow their supporting solid; **Through all** regenerates against its current depth. **Preview** rebuilds the complete solid in a temporary view; **Apply** commits one Undo step and **Cancel** restores the original. Invalid edits stay in the editor with an explanation, leaving the project unchanged. Features can be named and cuts/joins suppressed and enabled without deleting their inputs. A suppressed build step passes its original target through to later features.
- **Sketch dimensions & constraints:** Draw a sketch, then choose **Dimensions & constraints**, or edit an original sketch in **History → Edit sketch → Dimensions & constraints**. Tap numbered lines (Shift-tap for a second line, or use the selectors), choose a length in mm, line angle to X, angle between two directed lines (0–180°), or circle diameter. Horizontal, vertical, parallel and perpendicular relations solve together with dimensions. Rectangle sketches retain square corners; a diameter makes an ellipse round. Click a dimension label or choose **Edit** to update or remove it. Conflicts leave the last valid sketch intact and explain what needs changing. Saved constraints drive the outline; remove them to edit points freely. The local solver preserves the starting configuration as closely as possible; unconstrained points remain free. **Preview** rebuilds the whole solid without changing the project; **Apply** commits one undoable edit, regenerating later holes, finishes, shells and build features. Loft and Sweep profile editors include the same dimension controls. All definitions survive project save/reopen and drive printable geometry rather than becoming annotations.
- **Loft:** **Build → Loft between sketches** keeps 2–16 ordered profile sketches. Choose a profile and edit its outline, size, centre, plane, position or turn. Add, remove or reorder sketches; choose smooth or ruled sides in Loft settings. Draw custom profile points, enter coordinates, or copy an outline from an existing solid’s sketch or the current sketch drawing. Copies are independent and retain this profile’s placement. The 3D view shows the draft profiles. **Make loft** adds a closed editable solid in one Undo step. History exposes each profile under Loft; later solid operations rebuild after edits.
- **Sweep:** **Build → Sweep a sketch along a path** carries a closed profile along an open 3D path with 2–64 points. Draw and drag the path in front, top or side projection; use exact point fields or x,y,z coordinates to place it in mm. Smooth paths interpolate all points; straight paths support miter or round transitions. The section uses minimum twist transport; set its initial turn in degrees. The profile is automatically perpendicular to the initial tangent and follows the path from its first point. **Make sweep** stores the profile, path and settings; History exposes the sketch and path separately. Preview, Apply, Cancel, Undo and later rebuilding preserve original inputs. Precision operations have a 45-second limit; timed-out workers restart without applying the edit. Both tools generate closed boundary representations and printable STL; invalid outlines, collapsed lofts or impossible path bends fail without committing partial results.
- **Shell:** select one solid, then **Build → Shell · hollow a solid → Pick open faces**. Tap whole faces to mark openings in pink; drag to orbit. Set wall thickness in mm and choose **Preview shell**. Walls grow inward and preserve the outside size. Clear the openings for an enclosed cavity. Apply stores a reversible Shell step with the original solid inside it. In **History**, edit the thickness or **Reselect open faces** on the intact input; later holes, edge finishes and other features rebuild automatically. Suppress bypasses the shell, and the timeline can show its original solid. Geometric face references survive dimensional edits; removed or ambiguous faces and impossible wall thicknesses stop safely without applying a partial result. Projects retain the feature and openings; STL contains the actual hollow geometry.
- **Fillets & chamfers:** select one solid, then **Build → Fillet & chamfer edges → Pick edges**. Tap an edge to toggle it, including complete circular rims and hole entrances; drag to orbit. Select several edges or use **Select all edges**. Pink marks selected edges. Choose a **Fillet** radius or an equal-distance **Chamfer** setback in mm, then **Preview finish**. Apply commits one reversible feature and Cancel keeps the original. History retains its source solid, size, mode and selected edges; change the size or use **Reselect edges** to show the original sharp input again. Later operations rebuild, and suppression bypasses the finish. References use geometry and ordered concentric rims rather than temporary mesh indices. If an upstream edit removes or ambiguously changes an edge, the edit stops safely and offers reselection. Oversized radii or intersecting bevels show an error without applying partial results. Smooth surface seams and triangle diagonals are excluded from selection. These are real solid changes in the printable STL.
- **Timeline:** the strip under the workbench shows the selected solid's construction in build order. Tap a step or move the playhead to inspect earlier geometry; **Latest** restores the complete solid. Tree and timeline paginate instead of scrolling. Timeline rollback and edit previews never enter the saved project or STL; return to Latest, or apply/cancel an edit, before continuing construction or exporting. Earlier project recipes remain editable and recognized flat-face sketches acquire references when edited. If a supporting flat face disappears, rebuilding stops with an error; restore that face or change the sketch to a fixed workplane. Sketch point dragging, exact point coordinates and an editable coordinate list support custom profiles.
- **Print:** export all visible 3D layers, the current layer or selected visible pieces as binary **STL**. Export unions overlapping solids, computes outward facet normals and can move the bottom to Z=0. **Check solid & size** reports millimetre dimensions, volume and triangle count against the entered printer build volume. STL carries geometry; use **Save project** to retain colours, editable recipes, feature history, layers and the painting. Open the STL in a slicer to choose orientation, supports and print settings.

The local solid kernel is [Manifold](https://manifoldcad.org/) (Apache-2.0), with [Three.js](https://threejs.org/) (MIT) for the workbench. Modelling and STL generation run in a dedicated worker. Sketches are converted to closed volumes and boolean operations remove internal overlaps rather than exporting intersecting display meshes. Curved surfaces are tessellated with 96/128-segment detail for printing. Each 3D layer supports 128 top-level pieces, with bounded construction depth; layers share the existing 16-sheet document limit. Project validation rejects invalid dimensions, workplanes, IDs and singular transforms before replacing the document.

Precision edge finishing and shelling use [Replicad 1.1.0](https://replicad.xyz/) (MIT) and its [OpenCascade.js build](https://github.com/sgenoud/replicad/tree/e4b05f67dc4e2393a876ce8c5064a9c93db05bf1/packages/replicad-opencascadejs) (LGPL-2.1). The separate WASM module loads locally on demand when picking edges or faces, or rebuilding a saved precision feature. Primitives, sketches, revolutions and booleans are reconstructed as boundary representations for native lofts, sweeps, constant-radius fillets, symmetric chamfers and inward-offset shells, then triangulated with 0.005 mm deflection for the display and STL kernel. Complex solids with nonuniform body scaling use sewn, merged surface patches; editing original dimensions in History keeps curved inputs analytic. License texts are distributed under `licenses/`. No images or models are uploaded.

Keyboard in the workshop: **W/E/R** move/rotate/resize, **F** fit, **Shift-click** select more, **Delete** remove, **Ctrl/Cmd D** duplicate, **Ctrl/Cmd Z / Shift Z** undo/redo, and **Ctrl/Cmd S** save an editable project. **?** opens workshop help. Normal painting shortcuts resume when you return to Paint.

### Code studio: real OpenSCAD

In **3D workshop → Code → Open Code studio**, write code beside an orbitable preview. **Preview**, **F5**, or **Ctrl/Cmd+Enter** renders with the official OpenSCAD 2026.10.27 WebAssembly engine and Manifold backend. Optional Auto preview starts when enabled and rebuilds after edits; **Cancel render** stops a busy worker. The older limited interpreter is no longer used by the editor. Standard OpenSCAD syntax and semantics, including functions, modules, children, comprehensions, declarative assignments, arbitrary transforms, Minkowski sums, text and imported geometry, run in OpenSCAD itself.

**Open .scad** opens a standalone file. For designs using relative includes, use **Project files & libraries → Open folder**, then choose the **Entry script**. **Edit file** switches the editor to a helper or library without changing which entry is rendered. Edits to every source file are retained with the project; native parser errors select the affected file and line. Folder paths are preserved. The standard MCAD library is bundled. Other libraries can live in the project root or its libraries directory. **Add files** supplies additional assets and fonts; use Open folder when their directory structure matters. Missing includes/imports stop rendering rather than quietly accepting partial models. Files execute locally in a disposable worker with a virtual filesystem; they cannot read arbitrary files from your computer. Absolute desktop paths must be changed to project-relative paths.

**Add to scene** creates a workshop solid. **Edit selected solid’s code → Update selected** replaces its geometry while retaining placement, rotation, scale and colour. Both actions undo in one step. Solids support Join/Cut, Paint annotations and STL export. **Save Project** retains source, entry path and dependency bytes (format 13; older formats remain readable). **Save .scad** exports the currently edited file only, so save the project as well when using dependencies. Unapplied code remains a session draft until explicitly saved or applied. Parameter controls expose only unique top-level numeric constants, including exponent notation; they never rewrite module-local or commented assignments. File loading disables stale previews immediately, and cancellation or closing the editor stops its current render. Echo output is bounded; echoed words such as "ERROR:" are not treated as diagnostics.

This uses OpenSCAD's rendered solid output (desktop F6), not its OpenCSG preview or desktop GUI. STL output does not retain colours, background modifiers or animation; pure 2D output must be extruded before adding it to the 3D workshop. Noto Sans is bundled; add the specific TTF/OTF fonts used by a design for exact lettering. Browser/workshop limits remain: 2 MB source, 2,000 dependency files totalling 20 MB, five minutes per render, 200,000 output triangles and coordinates within ±10,000 mm. These limits mean arbitrary desktop projects are not guaranteed to fit, despite using the real language engine.

**Help wiki** opens an in-app, searchable guide without leaving the editor. It includes 68 authored topics spanning modelling operations, the core language, built-in calculations, workflow and practical recipes, plus a catalogue of all 42 bundled MCAD source files with searchable declarations and original comments. Related topics and Back/Forward support browsing. Each of the 70 runnable examples has an isolated orbitable preview; examples with file dependencies supply those files to their own temporary renderer. Previewing help examples never changes the draft or scene. Copy code transfers the example text when you choose to use it. Experimental and desktop-only features are explicitly distinguished from supported solid modelling. Reference coverage and every runnable example are checked by the existing test suite.

The Code studio **Example → Load example** menu includes five larger projects: **Spiral lattice lantern** (crossing twisted ribs), **Orbital sculpture** (intersecting revolved rings), **Twisted wave pen pot** (a calculated fluted outline and hollow interior), **Rocket desk organiser** (tapered cup, swept fins and portholes), and **Castle gatehouse** (hollow towers, battlements and an arched entrance). Each has commented source, editable dimensions and suggestions for variation, and needs no extra files. These native-engine examples extend the five original starters; legacy project compatibility is tested separately. Default models and a parameter variation of each are checked for closed, connected geometry.

In-article buttons jump directly to either level or the examples. ## Super resolution

Enable **Advanced mode**, then choose **More → Advanced → Super resolution**. Choose **2×** or **4×**, move the yellow box on the overview onto an interesting detail, then try **Preview detail**. Click or drag to move the box, use arrow keys for fine movement, and choose a 64, 128 or 256-pixel sample. Switch **Before / Enhanced** to compare that same selected area. **Enhance whole image** processes the full visible picture, including saved Photo lab adjustments, layers and crop. **Save enhanced PNG** downloads a larger copy; the editable document is never resized, flattened or replaced. The close button and Escape cancel immediately, including during model loading and inference.

Enhancement uses the separate pretrained [ESRGAN Thick 2× and 4× models from UpscalerJS](https://upscalerjs.com/models/available/upscaling/esrgan-thick/) (MIT), with 10 residual-in-residual dense blocks. Models run in a dedicated worker using TensorFlow.js WebGL, with the same neural network on CPU when WebGL is unavailable. Mirrored borders and 32-pixel tile context limit edge and seam artefacts. Real colours extend into transparent margins before RGB inference; alpha is resampled separately and clear pixels remain clear. Generated detail is an estimate; compare it with the original before saving.

The runtime and models load only when enhancement starts. Each model is about 29 MB and is served from the app's own origin; images are never uploaded. Vite serves model assets from the pinned npm package in development and includes only the two required scales plus their license in production. No external model CDN or API key is needed. Whole-image enhancement streams PNG row bands instead of allocating a giant canvas. Both scales work on every supported imported picture, up to 16384 pixels per output edge; the old 32-megapixel export restriction no longer blocks the action. The selected detail is retained for comparison, and the full PNG is ready to download when processing completes. Large AI jobs can take time; tile progress and immediate cancellation remain available. Normal painting keeps its existing size limits.

## Rendering checks

With the dev server running, open `/tests/painting.html` for browser canvas regression checks and a visual sample sheet. These also cover layers, redo, transforms, text, image codecs, project round-trips and Photo lab's tonal controls, curves, white balance, detail, lens mapping, preview cancellation, full-size apply and crop/undo. CAD checks validate closed edges, physical volume, boolean results, reversed sketches, face extrusions, partial/hollow revolutions, STL winding, worker output and project round-trips. `/tests/mobile.html?frame=390x844` (or `320x568`, `844x390`) checks phone layouts, photo adjustment groups, real 3D handle drags, face sketches, alignment, face snapping, 3D layer transfers and printing controls. Add `&preview` for an interactive app preview at that size, or `&cad-only` to run just CAD checks. `/tests/painting.html?cad-only` runs just solid-kernel checks. Test pages remain excluded from the production build.

`npm test` runs the full painting suite and desktop/three phone layout suites in a separate headless Chrome process. It starts its own loopback dev server, uses disposable browser contexts, writes JSON results and screenshots under `test-results/`, and exits unsuccessfully if any check or uncaught page error fails. It never connects to an open browser profile or controls the desktop. Use `-- --channel chromium` for Playwright's installed Chromium, or `-- --out <folder>` to choose the evidence folder. `npm run test:photo-reset -- --fixture <saved-project>` runs the automated Reset/Cancel/Done/Undo/Redo/fresh-reopen workflow and retains real project/PNG downloads; the fixture should contain saved non-default photo settings. Add `--production-url <loopback-url>` to test a production preview. These test counts remain separate from the 349 acceptance-case ledger and do not certify physical input or assistive technology.
